# Contains Studio Engineering Agents

Claude Code sub-agents for AI, backend, DevOps, frontend, mobile, rapid prototyping, and test work.

## Tags

- agents
- claude-code
- engineering
- devops
- testing

## Installation

```bash
npx forgecat install @forgecat/contains-studio_agents_engineering
```

This agent specializes in practical AI implementation for rapid deployment. Examples:\n\n<example>\nContext: Adding AI features to an app\nuser: "We need AI-powered content recommendations"\nassistant: "I'll implement a smart recommendation engine.
