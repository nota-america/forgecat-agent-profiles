# Ponytail

Lazy senior developer mode for AI agents, with YAGNI, standard-library-first, native-first, and minimal-code guidance packaged as skills, commands, rules, and lifecycle hooks.

## Tags

- yagni
- minimalism
- code-review
- productivity
- hooks

## Installation

```bash
npx forgecat install @forgecat/dietrichgebert_ponytail
```

## Skills / Agents / Commands

- **ponytail** - Persistent lazy senior developer mode with lite, full, and ultra intensity levels. `skill`
- **ponytail-review** - Diff-focused over-engineering review that reports what to delete or simplify. `skill`
- **ponytail-audit** - Whole-repo over-engineering audit for deletion, stdlib, native, YAGNI, and shrink findings. `skill`
- **ponytail-debt** - Reads `ponytail:` comments into a shortcut debt ledger. `skill`
- **ponytail-help** - Quick reference for Ponytail modes, skills, commands, and deactivation. `skill`
- **ponytail** - Switch Ponytail intensity level. `command`
- **ponytail-review** - Review changes for over-engineering. `command`
- **ponytail-audit** - Audit a whole repo for over-engineering. `command`
- **ponytail-debt** - Harvest `ponytail:` comments into a ledger. `command`
