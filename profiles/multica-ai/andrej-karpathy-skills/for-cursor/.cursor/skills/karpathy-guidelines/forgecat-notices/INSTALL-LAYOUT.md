# ForgeCat installation layout

The upstream documents under `upstream/` are preserved verbatim and describe source-repository paths and alternative native installation commands. They are not local setup commands required after ForgeCat installation. The skill is installed by the host skill adapter. Canonical `rules/CLAUDE.md` and `rules/karpathy-guidelines.mdc` preserve the two instruction sources; the latter retains `alwaysApply: true`. Project rule delivery follows the host adapter. Current home adapters receive the skill but do not directly install these project rules, so home support remains Partial until a separately reviewed equivalent instruction binding is provided. Upstream plugin JSON files contain packaging metadata only; they are excluded from this skill/rule profile and remain available at the pinned source.
