# Vercel Labs Skills

Skill package focused on discovering and installing reusable agent skills from the open skills ecosystem.

## Tags

- skills-discovery
- vercel-labs
- agent-skills

## Installation

```bash
npx forgecat install @forgecat/vercel-labs-skills
```

## Skills

- **find-skills** — Helps users discover and install agent skills when they ask questions like "how do I do X", "find a skill for X", "is there a skill that can...", or express interest in extending capabilities. This skill should be used when the user is looking for functionality that might exist as an installable skill. `skill`
