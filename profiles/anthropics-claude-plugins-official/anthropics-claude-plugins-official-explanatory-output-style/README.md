# explanatory-output-style

Adds educational insights about implementation choices and codebase patterns (mimics the deprecated Explanatory output style)

## Tags

- anthropic
- claude-official
- plugin

## Installation

```bash
npx forgecat install @forgecat/anthropics-claude-official-explanatory-output-style
```

## Hooks

- **sessionstart-1** — Explanatory mode hook that adds educational insights instructions

## Commands

- Hook-only plugin (no slash commands).
