# Agent Browser Skill Data

Agent-browser workflow skills for core browser automation and specialized AgentCore, QA, Electron, Slack, and Vercel Sandbox tasks.

## Installation

```bash
npx forgecat install @forgecat/vercel-labs_agent-browser_skill-data
```

## Skills

- **core** - Core agent-browser workflow for navigation, snapshots, interactions, extraction, screenshots, sessions, authentication, and troubleshooting.
- **agentcore** - Run agent-browser on AWS Bedrock AgentCore cloud browsers.
- **dogfood** - Systematically explore and test web applications with reproduction evidence.
- **electron** - Automate Electron desktop apps through Chrome DevTools Protocol.
- **slack** - Interact with Slack workspaces using browser automation.
- **vercel-sandbox** - Run agent-browser and Chrome inside Vercel Sandbox microVMs.
